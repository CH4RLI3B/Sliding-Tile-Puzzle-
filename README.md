# Sliding-Tile-Puzzle-
#5×5 Tile Puzzle Game

#Overview

This project is a Python-based 5×5 tile puzzle game developed as part of my computer science studies. The game uses a grid-based board to represent and manipulate tile positions, providing a foundation for implementing puzzle mechanics and state-based problem-solving.

The project focuses on object-oriented programming, two-dimensional lists, grid manipulation and logical problem-solving in Python.

**Features**
5×5 Grid: Represents the puzzle board using a two-dimensional list.

Board Class: Organises the board's structure and functionality using object-oriented programming.

Tile Representation: Uses letters and numerical values to represent tiles and their states.

Grid Manipulation: Supports identifying tile positions and modifying the board.

Testing: Uses test states to check board configuration and functionality.

Formatted Output: Displays the board as a structured grid for easier readability.

#How It Works

The game represents the puzzle as a 5×5 grid. A Board class manages the board structure, while individual positions store values representing the tiles.

The program can access specific positions, identify tile values and modify the grid according to the rules implemented in the code. Test boards are used to check that the grid is represented and manipulated correctly.

**Learning Objectives**

This project provides practical experience in:

Designing classes and methods in Python.

Working with two-dimensional data structures.

Accessing and updating individual grid positions.

Implementing conditional logic to manage tile states.

Testing program behaviour using predefined board configurations.

Developing structured, maintainable code.
